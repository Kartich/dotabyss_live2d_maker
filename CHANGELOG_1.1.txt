Dot 离线资源维护器 1.1 更新记录
================================

新增
----
1. 设置区支持粘贴完整 catalog_1.bin URL，自动识别版本号并解析 Bundle 基础地址。
2. 新增“资源表 / 指定下载”页，直接展示 Catalog 的完整 Bundle 清单，支持关键字、人物 ID、剧情 ID、类别和资源范围筛选。
3. 资源表支持多选下载、下载当前筛选结果、分页浏览，以及查看逻辑扩展名、Catalog Hash、关联人物/剧情 ID 和原目录推断。
4. 新增人物特征 ID（9 位）关联下载：尝试归集人物立绘、剧情文本、Live2D、语音和其他可明确关联的 Bundle。
5. 新增按 Unity Bundle 内部 Container 路径提取；资源内部存在原始路径时优先保留，Bundle 名称推断路径仅用作回退。
6. 导出人物资源清单 JSON/CSV；可识别的剧情背景、BGM、SE 依赖会追加下载，人物目录中保留关联副本，并维护共享公共资源池。
7. Catalog 下载采用临时文件并校验可识别 Bundle 数量，校验成功后才替换目标文件。

保持
----
原下载、旧版剧情资源检查、补全、索引维护等功能仍保留；它们的旧项目路径校验并未改成通用解析。新游戏的资源表、指定下载和按 Bundle 内部路径提取是独立入口。

测试范围
--------
本版通过 Python 语法检查、Catalog URL 解析与本地 Catalog 下载校验、23,635 条资源表加载、500 条分页、人物 ID 搜索和 GUI 冒烟测试。当前构建环境未安装 UnityPy，没有在本构建环境下载并验证真实游戏 Bundle 的完整解包结果。
