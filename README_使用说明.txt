Dot 离线资源维护器 1.2 使用说明

一、界面划分
1. “播放器维护”：旧版与播放器配合的下载/处理、资源检查与自动修复、索引更新、公共音频整理、运行日志都集中在这个工作区。
2. “独立人物资源提取”：完整 Catalog 资源表、筛选检索、多选指定下载、人物特征 ID 关联资源集、原目录提取、提取任务日志都集中在这个工作区。
3. 右上角“设置”：统一调整播放器项目目录、本地 Catalog、Catalog 完整下载地址、Bundle 缓存、人物资源提取目录、资源表输出目录、下载线程、是否提取以及是否追踪公共 BG/BGM/SE 依赖。

二、资源表
程序启动时自动读取本地 catalog_1.bin 并生成/刷新资源表。首次没有现有表时，会生成完整资源表和初始资源清单。通过“设置 → 下载并更新 Catalog”下载新版本后，程序会比较更新前后的 Bundle 名称并自动覆盖新增资源表。普通启动、下载资源后的状态刷新、点击“重新载入本地 Catalog”只更新当前表，保留上次新增资源清单。
默认输出到 resource_tables：
- 资源表.csv / 资源表.json：当前完整资产表，始终覆盖同名文件。
- 新增资源表.csv / 新增资源表.json：相对上一次 Catalog 更新新增的 Bundle；每次更新直接覆盖，不保留历史备份。
- 资源表更新信息.json：本次记录数量和更新方式。
第一次建表没有历史基线，因此“新增资源表”会收录初始资源全集；后续 Catalog 更新只列新出现的 Bundle 名称。
资产表只保留 Bundle 名称、资源类型、范围、人物特征 ID、关联剧情 ID、目录推断和本地下载状态，不输出独立 Hash / 扩展名列。

三、指定下载
资源表支持关键字、资源类别、资源范围筛选。可按住 Ctrl 或 Shift 多选，或使用“全选本页”；跨页已选项会保留。点击“下载选中项”只下载已选记录，“下载当前筛选全部”会下载当前筛选的所有记录。

四、人物资源提取
输入 9 位人物特征 ID 后，可按 Catalog 中可识别的立绘、剧情、Live2D、语音、图标及其他关联关系下载。开启公共依赖选项后，会继续解析已提取剧情文本中可识别的 abg/BGM/SE 编号，把对应资源放进人物“公共资源”目录，并在共享公共资源目录留可复用副本。

五、按原目录提取
若 UnityPy 能读到 Bundle 的 Container 路径，程序优先按原始路径提取；否则使用 Catalog 命名推断的路径。Catalog 推断路径不是内部对象路径的保证，建议先选择少量 Bundle 验证输出结构。

六、安装与启动
1. 安装 Python 3.10 或更新的兼容版本。
2. 在本目录执行：python -m pip install -r requirements.txt
3. 双击“启动_Dot离线资源维护器.bat”。
4. 如需实际解包 Unity Bundle，必须成功安装 UnityPy；若下载成功但解包报缺依赖，检查 requirements.txt 的安装输出。

本版本保留旧播放器维护流程，但没有将独立人物资源输出写入播放器 data/data_r18_all，两个功能区的路径和用途是独立的。
